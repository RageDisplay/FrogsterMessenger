# Релизная сборка

Из папки `client`, в PowerShell:

```powershell
# сервер с доменом
.\tool\build_release.ps1 -Server chat.example.com -Version 1.0.0

# сервер на голом IP с собственным сертификатом
.\tool\build_release.ps1 -Server 203.0.113.5 -Fingerprint ABCD-1234-... -Version 1.0.0
```

- `-Server` — адрес, который будет подставлен на экране входа. Друзья всё
  равно могут ввести другой.
- `-Fingerprint` — нужен только серверу на голом IP с собственным
  сертификатом. Возьмите его на сервере командой `sudo frogster fingerprint`
  (8 групп по 4 символа) и вставьте как есть. Он вшивается в сборку, и
  друзьям вводить его не придётся. Если команда отвечает, что сертификат
  публичный, — отпечаток не нужен.
- `-Version` — показывается в «Настройки → О приложении».

Если PowerShell откажется запускать скрипт («execution of scripts is
disabled»), запустите так:

```powershell
powershell -ExecutionPolicy Bypass -File .\tool\build_release.ps1 -Server chat.example.com -Version 1.0.0
```

Весь вывод Flutter и Gradle идёт прямо в окно — прогресс видно. Первая
Android-сборка долгая (Gradle скачивает зависимости), следующие быстрее.

Готовое лежит в `client\dist\`:

| Файл | Кому |
|---|---|
| `Frogster-<версия>.apk` | Android: скачать на телефон и открыть, разрешить установку из этого источника |
| `Frogster-<версия>-windows.zip` | Windows: распаковать в любую папку и запустить `frogster.exe` |

Windows-версия не подписана, поэтому SmartScreen при первом запуске может
показать «Windows защитила компьютер» → «Подробнее» → «Выполнить в любом
случае».

## Ключ подписи Android

`android\frogster-release.jks` и `android\key.properties` (пароли) лежат
только на этом компьютере и в git не попадают. **Сохраните обе копии в
надёжное место.** Android ставит обновление поверх, только если оно подписано
тем же ключом; потеряете ключ — друзьям придётся удалять приложение (вместе с
перепиской) и ставить заново.

Если `key.properties` нет, скрипт подпишет сборку debug-ключом и предупредит.

## Перед тем как раздавать

Сервер должен быть той же версии, что и приложение: в этой версии появились
новые таблицы и API. Запушьте изменения и на сервере выполните

```bash
sudo frogster update
```

Миграции применятся сами при старте.
